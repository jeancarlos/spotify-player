# Testes E2E — Todos os Fluxos do Spec

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar suite Playwright cobrindo todos os fluxos definidos no spec, incluindo login PKCE mockado, sem chamar a API real do Spotify.

**Architecture:** Playwright intercepta todas as chamadas à API Spotify via `page.route()`. Para telas autenticadas, `page.addInitScript()` pre-seeds sessionStorage com token falso antes do React montar — evitando o redirect para `/login`. O fluxo de login é testado separadamente mockando `accounts.spotify.com/authorize` e `/api/token`.

**Tech Stack:** Playwright, TypeScript, Vite dev server (porta 5174), react-i18next (pt-BR/en-US)

export async function setupLoginMocks(page: Page) {
  // Intercepta redirect para Spotify authorize — captura state e redireciona de volta

      status: 302,

      contentType: 'application/json',
      body: JSON.stringify({
        access_token: 'mock_e2e_access_token',
        refresh_token: 'mock_e2e_refresh_token',
        token_type: 'Bearer',
        expires_in: 3600,
      }),
    })
  )
}

/**
 * Configura estado autenticado antes do React montar.
 * DEVE ser chamado antes de page.goto() em cada teste que requer login.

export async function seedAuthState(page: Page) {
  await page.addInitScript(() => {
    sessionStorage.setItem('access_token', 'mock_e2e_access_token')
    localStorage.setItem('refresh_token', 'mock_e2e_refresh_token')
  })
  await setupApiMocks(page)
}
